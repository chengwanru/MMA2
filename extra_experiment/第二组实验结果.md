# Extra Experiment: MBSD（draft+target speculative decoding，不开QAVR）

**实验设置：** 这一组在跟第一组相同的compact memory prompt基础上，加上draft模型（2B）+ confidence-weighted memory bias + target verify的完整speculative decoding流程，但**不启用QAVR（视觉记忆路由）**——即`MMA_ENABLE_VISUAL_ROUTING=0`。跟第一组（target-only）的区别是加了SD；跟第三组（MMA2.0）的区别是没开QAVR。

**样本量：** 557题。

---
